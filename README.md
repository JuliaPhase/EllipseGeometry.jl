## Overview

> **Note:** this overview is a temporary README generated by AI (Claude) and has not yet been reviewed by the author.

EllipseGeometry is a small Julia package for working with ellipses: creating an ellipse from its centre, semi-axes and orientation, testing whether points lie inside it, and rotating or adjusting it together with an image. It is used, for example, to describe elliptical apertures in the Phase.jl packages.
